# Force Graph

Интерактивная симуляция force-directed графа: один HTML-файл, Tailwind через CDN, без сборки.

## Возможности

- Физика пружин, отталкивания и центральной гравитации
- Перетаскивание узлов мышью
- Двойной клик — добавить узел, правый клик — удалить
- Слайдеры для всех параметров симуляции
- Кнопки «+ Узел», «+ Кластер», «Перегенерировать»

## Локальный просмотр

Достаточно открыть `index.html` в браузере.

## Публикация на GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери источник **Deploy from a branch**.
3. Branch: `claude/initial-setup-LPeoi`, папка `/ (root)`.
4. Сохрани — через минуту страница будет доступна по адресу
   `https://<user>.github.io/<repo>/`.
